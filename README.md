# VitaTradingBot

Industry-standard profitable crypto trading bot with modern GUI, supporting both DEX and CEX trading.

## Features

- **Multi-Wallet Support**: MetaMask, WalletConnect, and direct wallet import
- **Multi-Chain**: Ethereum, Polygon, BSC, Avalanche, Arbitrum, Optimism, Solana
- **Trading Strategies**: Mean Reversion, Momentum, Grid Trading, Market Making, Arbitrage
- **Risk Management**: Comprehensive position sizing, stop-loss, take-profit controls
- **Multi-Timeframe**: Support for 1m, 5m, 15m, 30m, 1h, 4h, 1d timeframes
- **Trading Hours**: Configurable trading hours and days
- **Paper Trading**: Test strategies risk-free with virtual funds
- **Backtesting**: Historical strategy testing with comprehensive metrics
- **Real-Time P&L**: Live profit and loss tracking
- **Real-Time Dashboard**: Modern trading platform UI

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm or yarn

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
npm run build:electron
```

### Testing

```bash
npm test
npm run test:coverage
```
